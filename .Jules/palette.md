## 2024-05-23 - macOS Window Controls Pattern
**Learning:** Users expect "macOS-style" window controls (Red/Yellow/Green) to reveal function icons (X, -, +) on hover for clarity, even in a "hacker" theme.
**Action:** Use `group` on the container and `opacity-0 group-hover:opacity-100` on child icons to implement this "reveal on hover" interaction for future control groups.
