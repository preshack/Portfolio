# Palette's Journal

This journal tracks critical UX and accessibility learnings for the project.

## 2024-05-21 - Standardizing System Affordances
**Learning:** In thematic interfaces (like a fake OS), users expect standard system controls (traffic lights) to behave consistently with the mimicked system (macOS).
**Action:** When using OS-like patterns, ensure controls (Red/Yellow/Green) map to expected behaviors (Close/Minimize/Maximize) and include accessibility labels.
